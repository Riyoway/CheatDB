# CheatDB Web

An independently built static browser for https://db.riyo.me/cheatdb/. Vite + TypeScript, without a runtime framework or database service.

## Develop and build

Use Node 22.13 or later (tested version pinned in `.node-version`). From this directory:

```sh
npm ci
npm run dev
npm test
npm run build
```

Development: http://127.0.0.1:5173/cheatdb/. Both `dev` and `build` generate web data first. `npm run serve:public` serves the built browser at http://127.0.0.1:18473/cheatdb/.

## Data flow

```text
data/cheatdb.db (read-only, canonical)
  → scripts/build-web-data.mjs
  → exports/web/data/catalog.json
  → exports/web/data/<DB SHA-256 prefix>/games/<game ID>.json
  → exports/web/data/<DB SHA-256 prefix>/codes/<game ID>-<part>.json
  → Vite publicDir copies exports/web into apps/web/dist
```

The catalog contains only game search metadata and counts. Selecting a game loads a cheat-name/build/region index. Expanding a cheat loads its code chunk on demand; chunks are limited to 100 cheats or approximately 512 KiB. Codes larger than that soft target get their own chunk. The build rejects files approaching the 25 MiB Pages per-file limit and checks the 20,000-file limit. Existing exports are left in their original directories and formats.

Database integrity, foreign keys and schema version are checked before generation. The source database's SHA-256 is checked before and after generation. Paths include the database digest, preventing an older catalog from silently resolving to a different game's codes after a dataset update. Data responses revalidate; if an old snapshot has been removed after deployment, the UI offers a reload. Author credits, aliases, notes, region, build and code text are preserved.

`packages/` is intentionally unused. There is no workspace framework, duplicated SQLite file, Worker, or portal application in this repository.

## Routing and Cloudflare Pages

Create a **separate Pages project** connected to `Riyoway/CheatDB`:

| Setting | Value |
| --- | --- |
| Root directory | `apps/web` |
| Build command | `npm run build` |
| Build output | `dist` |
| Environment | `NODE_VERSION=22.22.3` |
| Custom domains | **Do not add `db.riyo.me`** |

`wrangler.jsonc` describes only the Pages build output; it is not a routing Worker. No Cloudflare CLI is needed to build or test locally. The production `cheatdb` Pages project is connected to this repository; pushes to `main` deploy automatically. Its origin is `https://cheatdb.pages.dev`, while the public entry point is `https://db.riyo.me/cheatdb/`.

The Database repository's Worker owns the route mapping and removes `/cheatdb` only when proxying to this Pages origin. Assets and fetches generated by this frontend always use `/cheatdb/` on the public domain. Do not change Vite's base to `/`, prepend `/cheatdb` to the physical output directory, or configure a second custom domain. Deep routes (`switch/`, `3ds/`, `wiiu/`, `nes/`) are handled by the SPA via `_redirects`.

To verify the real routing shape without Cloudflare tools, run these in separate terminals:

```sh
# CheatDB/apps/web
npm run build
npm run serve:origin
```

```sh
# Database (separate sibling checkout)
npm run dev
```

Open http://127.0.0.1:18474/ for the portal and http://127.0.0.1:18474/cheatdb/ for the proxied browser. The local Pages-like origin on port 18475 serves flat assets; direct origin browsing is not the public entry point.

## Design

The browser follows Resend's application dashboard: a fixed 232px sidebar, compact sans-serif headings, pill-shaped platform tabs, black surfaces, subtle gray borders, and rounded panels. Game search and code browsing are visible immediately. The root Database portal retains the large display heading and introductory actions.

Inter and Commit Mono are bundled through their OFL-licensed Fontsource packages. The CheatDB browser makes no external font, image or video requests and contains no hero illustration or marketing section. The dataset remains read-only. Keyboard focus, a skip link, responsive layout and reduced-motion support are included; search and filtering update immediately.
